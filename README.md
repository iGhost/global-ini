### Installation instructions

- Download latest release of [Data.zip](../../releases/latest/download/Data.zip).
- Extract its contents to the Star Citizen game root directory: (`Star Citizen\LIVE`)
- ⚠️ The global.ini file changes with every patch or update. After updating the game, either update the file or delete the following folder to restore the latest in-game text: `Data\Localization\english`
